# oficina-mecanica-autenticacao

Função serverless de autenticação por CPF da oficina mecânica: valida o cliente, consulta a existência e o status dele no banco de dados e emite o token JWT que dá acesso às APIs protegidas. Java e AWS Lambda, atrás do API Gateway.

Faz parte da solução descrita em [oficina-mecanica-api](https://github.com/paulo-juchimiuk/oficina-mecanica-api).
